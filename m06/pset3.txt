We used to test human-generated programs because humans can make mistakes when writing code. We may make a syntax mistake, miss an input check, or write a wrong logic. Testing helped us make sure the program is working, and working in the expected way.
Although AI is very good at generating programs nowadays, we still need to ask AIs to build test suites because AIs cannot guarantee that their generated code is correct. They probably would not make syntax mistakes, but they may still miss edge cases or misunderstand our requirements. Generating the test suites helps us better understand the generated program and find these mistakes.
